# MiMo 平台

这份文献笔记整理 MiMo 平台的主要入口页，重点是把文档和平台地址拉成一张入口表。

## 关键事实

| 用途 | URL |
|------|-----|
| 官方文档 | `https://platform.xiaomimimo.com/docs/welcome` |
| 模型发布页 | `https://platform.xiaomimimo.com/docs/updates/model` |
| 模型超参 | `https://platform.xiaomimimo.com/docs/quick-start/model-hyperparameters` |
| OpenAI API 文档 | `https://platform.xiaomimimo.com/docs/api/chat/openai-api` |
| Anthropic API | `https://token-plan-cn.xiaomimimo.com/anthropic` |
| MiMo 官网 | `https://mimo.xiaomi.com/` |
| AI Studio | `https://aistudio.xiaomimimo.com/` |

## 关键摘录

| 类别 | 内容 |
|------|------|
| 文档形态 | 官方文档站是 SPA（单页应用） |
| 抓取限制 | `web_fetch` 抓不到正文时，需要转浏览器自动化路线 |
| 平台作用 | 是所有 MiMo 规格、接口、更新信息的上游入口 |

## 值得关注

- 这是典型的入口型资料页，价值在于“去哪找”，不在于“讲透模型”。
- 官方文档站是 SPA，知识库里应该保留入口，但正文采集要换工具。
- 后续新模型发布时，这页通常是第一落点。
