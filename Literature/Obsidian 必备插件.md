# Obsidian 必备插件清单

> 源：[[Raws/Obsidian 必备插件]] | 2026 年 5 月整理，基于三源交叉验证

## 核心发现

截至 2026 年 3 月，Obsidian 社区插件突破 2500 款。但真正「装了就有用」的核心插件不超过 20 款。这份清单按使用场景分组，每款都经过社区长期验证。

## 关键事实：四档分类

### 核心必装（零学习成本）
- Calendar — 侧边栏月视图日历
- Periodic Notes — 周/月/季/年记
- Recent Files — 最近文件列表
- Tag Wrangler — 批量标签管理
- Obsidian Git — 自动 Git 备份
- Linter — 保存时自动格式化

### 效率自动化（需配置）
- Templater — 动态模板引擎
- QuickAdd — 一键捕获到文件夹
- Tasks — 跨 vault 任务管理
- Dataview — 数据库查询（学习曲线最高，收益最大）

### 研究与写作
- Excalidraw — 手绘图表嵌入
- Better Export PDF — 带目录 PDF 导出
- Number Headings — 标题自动编号
- Export Image — 笔记导出 PNG

### UI 增强
- Iconize — 文件夹图标
- Novel Word Count — 字数统计
- List Callouts — 列表彩色标注
- Link Favicons — 外部链接图标

## 值得注意的点

- 插件选择原则：先核心后舒适、不追求数量、一次只加一个防冲突、定期清理
- 建议开局顺序：第一天 Calendar+Periodic+Recent → 一周后 Templater+QuickAdd+Linter → 一月后 Tasks+Dataview → 按需加其他
- 社区共识：**重点在方法不在插件**——Markdown + 双链才是 Obsidian 的核心能力
