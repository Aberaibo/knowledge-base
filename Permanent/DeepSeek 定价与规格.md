# DeepSeek 定价与规格

这页把 DeepSeek 当前官网里最适合做模型决策的两类信息捏到一起：规格和价格。现在最需要修正的一点是：[[DeepSeek-V4-Pro]] 的官网价格展示同时放了折后价和原价，当前有效价要按折后数字读，不是按原价读。

## 我的判断

从已公开数据看，DeepSeek 的基础规格给得很大方：1M 上下文、384K 最大输出、JSON、Tool Calls、thinking 都有。真正拉开差距的是价格，但现在更准确的说法应该是：[[DeepSeek-V4-Flash]] 是低价位候选，[[DeepSeek-V4-Pro]] 在折扣期也已经进入可比区间，不该再被误写成“当前还是特别贵得离谱”。

## 怎么用

| 决策目标 | 看什么 |
|----------|--------|
| 判断接入门槛 | 两者都支持主流现代能力 |
| 判断长上下文 | 两者都到 1M |
| 判断预算 | 先按当前有效价比，不要拿 Pro 原价做默认比较 |
| 判断旧配置升级 | 看旧模型名迁移到 v4 体系 |
