# MiMo 平台

[[MiMo 平台]] 是小米 MiMo 模型的官方入口集合页，最大的价值不是解释模型能力，而是告诉你去哪里找权威信息。

## 我的判断

这类页面适合做“入口笔记”，不适合堆太多解释。它的核心价值是把分散在 SPA（单页应用）文档站里的入口统一列出来，减少每次重找文档的成本。

## 怎么用

| 目标 | 入口 |
|------|------|
| 看模型发布 | 官方文档更新页 |
| 看参数定义 | 模型超参数页 |
| 走 OpenAI 兼容接口 | OpenAI API 文档页 |
| 走 Anthropic 协议 | Anthropic API 地址 |
| 做交互体验 | AI Studio |

## 横向比较

| 类型 | 入口 |
|------|------|
| 文档入口 | `https://platform.xiaomimimo.com/docs/welcome` |
| 模型更新 | `https://platform.xiaomimimo.com/docs/updates/model` |
| OpenAI 兼容接口 | `https://platform.xiaomimimo.com/docs/api/chat/openai-api` |
| Anthropic 兼容接口 | `https://token-plan-cn.xiaomimimo.com/anthropic` |
| Studio | `https://aistudio.xiaomimimo.com/` |
