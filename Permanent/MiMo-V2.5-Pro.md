# MiMo-V2.5-Pro

[[MiMo-V2.5-Pro]] 是 MiMo 系列里偏推理旗舰的型号，核心卖点是大上下文、强推理和 Agent 场景表现。

## 我的判断

如果任务重点是推理链、复杂工具调用或长上下文 Agent，这个型号比 [[MiMo-V2.5]] 更像主力。但代价也更直接：价格明显更高，而且超过 256K 上下文后成本再上一个台阶。

## 怎么用

| 场景 | 是否适合 |
|------|----------|
| 复杂推理 | 适合 |
| 多步 Agent | 适合 |
| 成本敏感批量任务 | 要谨慎 |
| 大会话持续聊天 | 要盯上下文长度 |

## 横向比较

| 维度 | MiMo-V2.5-Pro | [[MiMo-V2.5]] |
|------|----------------|---------------|
| 定位 | 推理旗舰 | 全模态通用 |
| 上下文 | 1M | 1M |
| 最大输出 | 131,072 | 131,072 |
| 多模态 | ❌ | ✅ |
| 价格 | 更高 | 更低 |
