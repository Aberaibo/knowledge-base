# MiMo-V2.5

[[MiMo-V2.5]] 是 MiMo 系列里更偏“全能型”的版本。它既有大上下文，也有全模态能力，所以更适合输入形态复杂的场景。

## 我的判断

如果任务需要图像、视频、音频和文本统一处理，这个模型比 [[MiMo-V2.5-Pro]] 更对路。它不是单纯“低配版”，而是路线不同：更强调全模态和综合 Agent 能力。

## 怎么用

| 场景 | 是否适合 |
|------|----------|
| 多模态输入任务 | 优先考虑 |
| 成本敏感但仍想保留大上下文 | 适合 |
| 纯推理极限任务 | 可以用，但未必首选 |
| 平衡能力和价格 | 比 Pro 更均衡 |

## 横向比较

| 维度 | MiMo-V2.5 | [[MiMo-V2.5-Pro]] |
|------|------------|-------------------|
| 路线 | 全模态通用 | 强推理旗舰 |
| 上下文 | 1M | 1M |
| 最大输出 | 131,072 | 131,072 |
| 多模态 | ✅ | ❌ |
| 价格 | 更低 | 更高 |
