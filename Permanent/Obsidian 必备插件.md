# Obsidian 必备插件

社区插件超 2500 款，真正「装了就有用」的不超过 20 款。以下是按场景分组的必备清单。

## 核心必装（零学习成本）

| 插件 | 干什么 | 为什么必装 |
|------|--------|-----------|
| Calendar | 侧边栏月视图，点日期开日记 | 不用日历你永远不知道哪天写过 |
| Periodic Notes | 周记/月记/季记/年记 | 时间维度结构化 |
| Recent Files | 最近打开的文件列表 | 几千个文件时搜索不如"最近" |
| Tag Wrangler | 批量重命名/合并标签 | 标签长了杂草一键收拾 |
| Obsidian Git | 自动 Git 备份和版本控制 | 笔记是资产，资产要有版本历史 |
| Linter | 保存时自动格式化 | 格式一致性靠机器不靠自律 |

## 效率自动化（需配置）

| 插件 | 干什么 | 使用场景 |
|------|--------|----------|
| Templater | 动态模板引擎（变量/日期/JS） | 新建笔记自动填元数据 |
| QuickAdd | 一键捕获到指定文件夹 | 闪念、灵感瞬间入库 |
| Tasks | 跨 vault 任务管理 | 散落各处的任务一个查询聚合 |
| Dataview | vault 当数据库查询 | 仪表盘、统计、自动索引 |

## 研究写作 & UI 增强

| 分类 | 插件 | 干什么 |
|------|------|--------|
| 研究 | Excalidraw | 手绘图嵌入笔记 |
| 研究 | Better Export PDF | 导出带目录的 PDF |
| 研究 | Number Headings | 标题自动编号 |
| UI | Iconize | 文件夹自定义图标 |
| UI | Novel Word Count | 文件夹字数/文件数统计 |
| UI | List Callouts | 列表条目彩色标注 |

## 选择原则

1. **先核心后舒适。** Calendar + Recent Files 装了就用，Dataview 可以慢慢学
2. **不追求数量。** 装了≠用了
3. **一次只加一个。** 防冲突
4. **定期清理。** 一周没用的卸载
5. **重点在方法不在插件。** Markdown + 双链是 Obsidian 真正的核心能力

## 建议开局顺序

```
第一次 → Calendar + Periodic Notes + Recent Files（立即好用）
一周后 → Templater + QuickAdd + Linter（消除重复劳动）
一月后 → Tasks + Dataview（自动化知识管理）
按需   → Excalidraw / Better Export PDF / Iconize
```
