# Obsidian 必备插件清单

> 来源：Obsibrain 2026 指南 + 少数派实测 + Reddit 社区共识，三源交叉验证

## 核心必装（零学习成本）

- Calendar — 侧边栏月视图，点日期自动开日记
- Periodic Notes — 周记/月记/季记/年记
- Recent Files — 侧边栏最近文件列表
- Tag Wrangler — 批量重命名和合并标签
- Obsidian Git — 自动备份到 Git
- Linter — 保存时自动格式化

## 效率自动化（需配置）

- Templater — 动态模板引擎（变量、日期、JS）
- QuickAdd — 一键捕获到指定文件夹
- Tasks — 跨 vault 任务管理（到期日/优先级/重复）
- Dataview — vault 当数据库查询（学习曲线高，回报最大）

## 研究与写作

- Excalidraw — 手绘图嵌入笔记
- Better Export PDF — 导出带目录 PDF
- Number Headings — 标题自动编号
- Export Image — 笔记导出 PNG 长图

## UI & 增强

- Iconize — 文件夹自定义图标
- Novel Word Count — 文件夹字数/文件数统计
- List Callouts — 列表彩色标注
- Link Favicons — 外部链接显示网站图标

## 选择原则

1. 先核心后舒适
2. 不追求数量
3. 一次只加一个插件防冲突
4. 一周没用的果断卸载
5. 重点在方法不在插件

## 建议开局顺序

第一次 → Calendar + Periodic Notes + Recent Files
一周后 → Templater + QuickAdd + Linter
一月后 → Tasks + Dataview
按需 → Excalidraw / Better Export PDF / Iconize
